# MODULE 02 — CHARACTER SIMULATOR

来源：`创作智能系统/2.txt`（原文逐字保留在本文件末尾）

## 调用时机

- 建人物卡
- 写到某个人物的选择时（尤其是配角、对手）
- 出现「人物崩了」「工具人」「为了推剧情让他犯蠢」
- 检查认知隔离：某人是不是知道了不该知道的事

## 人物卡（13 字段，缺一项即未完成）

```yaml
姓名：
人格：<三个词，互相有张力，例如「体面、记仇、怕欠人情」>
欲望：<想要什么，现在就要的那个>
恐惧：<最怕失去什么>
利益：<钱、权、名、命、情，具体到靠什么吃饭>
价值观：<什么事他绝对不做>
秘密：<不能让谁知道的事>
认知边界：<他确定知道什么 / 他误以为什么 / 他完全不知道什么>
记忆：<关键经历，带时间>
能力：<能做什么，上限在哪>
缺陷：<会让他做错决定的东西>
社会关系：<对每个人的实际态度，不是称谓>
当前目标：<这一卷里他要达成什么>
```

## 决策推演（每次写到该人物必做）

```
人物：<名字>
此刻想要：<当下这一小时的目标>
他知道：<只列他有渠道获知的信息>
他不知道：<本场与他相关但他不知道的>
他会选：<行动>
代价：<他愿意付的 / 他没想到要付的>
```

「他知道」里混进任何一条无渠道信息 → 认知隔离违规，P1。

## 自主性测试（三问）

1. 把主角换成另一个人，这场戏还成立吗？成立 → 配角有独立性；不成立 → 他可能只是功能位。
2. 这个人物有没有在本卷拒绝过主角一次？没有 → 危险信号。
3. 他做这个选择，是因为他的利益，还是因为作者需要？答不上前者的 → 重写该选择。

人物允许：拒绝、欺骗、误解、利用、背叛、帮助、做错决定、偏离作者预期。
这些都是**合法输出**，不得为了顺剧情抹平。

## 认知隔离台账

| 信息 | 谁能知道 | 获知渠道 | 获知章节 |
|---|---|---|---|

新增重大信息时必登记。渠道只认：亲见、听见、被告知（且告知者有动机）、文件、推断（需给出推断链）。

## 人格连续性

成长、变化、崩溃都合法，但必须有触发事件。检查方式：把他在第 1 章和第 N 章的同一条价值观并列，若相反，中间必须有能解释这一转变的场景；没有 → 补场景或改行为，不许改人设。

## 硬约束

- 人物不是主角的工具
- 不得为了方便剧情随意改变人格
- 档案状态为 PROPOSED 的人物不得在正文里当成既成事实使用（见 07）

---

## 原文

CHARACTER SIMULATOR：每个重要人物必须具备独立人格、欲望、恐惧、利益、价值观、秘密、认知边界、记忆、能力、缺陷和当前目标。人物根据自身动机和认知独立决策，不得成为主角工具。严格执行认知隔离，任何信息转移必须存在合理渠道。
