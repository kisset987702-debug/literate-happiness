# MODULE 05 — LANGUAGE QUALITY ENGINE

来源：`创作智能系统/5.txt`（原文逐字保留在本文件末尾）

## 调用时机

- 段落写完、全章通读前
- 「文笔油」「AI 味」「形容词太多」「读着假」

## 福楼拜八项（逐句过，专查「写不准」）

1. **观察是否准确**：写的是这个东西，还是「这类东西的一般印象」。
2. **材质是否具体**：木、铁、瓷、塑料、纸——不同材质的手感、声音、重量不同。
3. **形状 / 重量 / 位置是否合理**：一只手能不能拿住，举起来会不会晃。
4. **人体动作是否符合物理逻辑**：起身时脚在哪，转身要不要收肩，受伤后哪只手使不上力。
5. **空间关系是否清楚**：谁在谁左边，门在身后还是侧面，两人隔多远。
6. **动作是否连续**：上一个动作结束时手在哪，下一个动作从哪开始。
7. **感官是否具体**：气味是哪种气味，声音有多响（可类比）。
8. **是否有过度解释**：把读者自己能得出的结论又说了一遍。

## 废话清单（八类，见到就删）

| 类型 | 例子形态 | 处理 |
|---|---|---|
| 重复信息 | 同一事实两段内说两次 | 删后一次 |
| 重复动作 | 又一次「他皱了皱眉」 | 删或换具体反应 |
| 同义反复 | 「寒冷刺骨的冷风」 | 留一个 |
| 无效过渡 | 「时间一分一秒过去」 | 删，直接跳 |
| 无功能环境 | 天气/风景不与情绪或事件相关 | 删或改为有用 |
| 过度解释 | 动作后紧跟一句为什么 | 删解释 |
| 无意义心理 | 「他不禁想到很多」类空转 | 删或换成具体念头 |
| 不推进段落 | 读完这段，位置/关系/认知全没变 | 删 |

## 段落功能标注法（实用）

逐段旁注一个字母，只许一个主功能：

- **E** 推进事件　**C** 塑造人物　**I** 提供必要信息　**A** 制造氛围　**S** 建立悬念　**R** 改变读者理解

标不出字母的段落 → 删。
连续三段同一字母 → 节奏单调，调整。

## 量化阈值（自查用，超过即回看）

- 形容词密度：每 100 字超过 6 个修饰语 → 挑掉一半
- 解释句：动作描写后紧跟「因为 / 原来 / 这说明」的比例，应接近 0
- 「了」字密度、句首「他/她」连续开头超过 3 句 → 改写句式
- 连续三句同为「主语+动词+宾语」→ 打散

## 改写优先级

1. 先删（无效内容）
2. 再准（材质、位置、动作）
3. 后简（拆长句、去修饰）
4. 最后才是修辞

顺序颠倒会越改越油。

## 硬约束

语言标准：准确、克制、具体、有画面感。不堆砌修辞，不空洞抒情。
判读口径与 `story-deslop`、`lieflat-less-ai-tone` 一致，可交叉复核。
